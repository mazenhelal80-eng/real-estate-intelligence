# Real Estate Intelligence & AI Decision Engine

An end-to-end Machine Learning project for real estate business intelligence.

## Project Goals

* Business analytics
* Property price prediction
* Lead conversion prediction
* Customer segmentation
* Revenue forecasting
* Business anomaly detection

## Dataset

Synthetic real estate dataset covering development, brokerage,
and property management operations.

## Tech Stack

* Python
* Pandas
* NumPy
* Scikit-learn
* SQLAlchemy
* Jupyter
* Matplotlib
* Seaborn
